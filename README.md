# Building Information Classifier (BIC)

This repository contains the **Building Information Classifier** in an ontological representation using the **RDF/XML** syntax.

According to subparagraph "a" of paragraph 4 of the **Regulations on the operation of the State Information System for Urban Development in the Russian Federation**, approved by the Government of the Russian Federation on September 28, 2020, No. 1558, the classifier is recognized as a **subsystem** of the official urban development information system (also known as "Stroykompleks.RF").

---

## Format

The ontology is provided in **RDF/XML** format.

---

## Usage

To open and explore the ontology:

1. Download and install [**Protégé**](https://protege.stanford.edu/), a free and open-source ontology editor.
2. Launch Protégé.
3. Select **"Open..."** from the File menu.
4. Load the RDF/XML ontology file from this repository.

Protégé provides tools to browse, query, and edit the ontology structure.

---

The **Building Information Classifier** is a systematized set of codes and names designed to:

- Standardize;  
- Structure;  
- Unify data related to the design, construction, operation, and decommissioning of capital construction projects.

---

## Purpose of the Classifier

The Building Information Classifier (BIC) is used for:

- Standardizing the description of construction elements, processes, and resources;  
- Ensuring data compatibility among various stakeholders in the investment and construction process (architects, designers, contractors, clients, regulatory authorities, etc.);  
- Automating the processing of construction information in **BIM** (Building Information Modeling) systems.
